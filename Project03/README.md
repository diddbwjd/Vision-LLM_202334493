AI 외출 준비 도우미 
개요
사용자의 외출 목적에 맞는 준비물을 AI가 추천하고, 실시간 객체 탐지를 통해 가방 내부의 준비물을 확인하여 빠뜨렸을 가능성이 있는 물건을 안내하는 시스템입니다.
주요 기능
- 음성 기반 외출 목적 입력 : 사용자가 외출 목적을 음성으로 입력하면 STT를 통해 텍스트로 변환
- Gemma LLM이 외출 목적을 분석하여 필요한 준비물을 추천
- 맞춤형 준비물 리스트 관리 : 사용자가 AI가 추천한 준비물 목록 수정 가능, 자주 사용하는 준비물 목록은 즐겨찾기로 저장하여 사용 가능
- YOLO 기반 실시간 준비물 탐지
 : 사용자가 가방 내부를 카메라로 촬영하면 YOLO가 보이는 물건을 실시간으로 탐지
 : 탐지된 물건과 준비물 리스트를 비교하여 미확인 물체 탐지
- 미확인 준비물 안내
 : 확인되지 않은 준비물은 별도의 목록으로 표시
 : 화면과 음성을 통해 사용자가 빠뜨렸을 가능성이 있는 물건 음성과 텍스트로 안내
- 사용자 최종 확인
 : 탐지되지 못한 물건의 경우, 사용자가 직접 확인 완료 여부를 선택 가능
목적 
AI의 객체 탐지 결과를 보조 수단으로 활용하여 준비물 누락 가능성을 줄이기
기대 효과
사용자가 외출할 때 필요한 준비물을 보다 체계적으로 관리하고, 미처 확인하지 못한 물건을 다시 점검할 수 있도록 지원합니다. AI의 자동 인식과 사용자의 직접 확인을 결합하여 객체 탐지의 한계를 보완합니다.
